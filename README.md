# webtech-wheelhouse

This is the Wheelhouse web system for management. The wheelhouse shop is a bicycle repair shop operated by its owner. The purpose of this web system is to facilitate the operations occurring within said establishment to ensure better, faster, and more organized services to the clients, who will also get access to more tools to inform themselves about the shop, as well as facilitating contact between both.

Clients and staff will be able to access this site. The latter is composed by mechanics and counter staff, both of which have full access to the system (for now) but with different roles and responsibilities within it.
